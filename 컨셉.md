# 레트로 다방 카페 인덱스 페이지 디자인 프롬프트

## 주조 3색

| 역할   | 이름      | HEX       | 쓰임                                                                |
| ------ | --------- | --------- | ------------------------------------------------------------------- |
| 바탕   | 연유 크림 | `#F4E9D4` | 페이지 배경, 카드 배경. 누렇게 바랜 다방 벽지와 메뉴판 종이 느낌    |
| 메인   | 월넛 고동 | `#3B2418` | 본문 텍스트, 헤더/푸터 배경, 테두리. 짙은 원목 테이블과 쌍화차 색   |
| 포인트 | 팥 버건디 | `#8C2F2B` | CTA 버튼, 활성 탭, 링크, 강조 배지. 다방 벨벳 소파와 빨간 성냥갑 색 |

보조색으로 겨자 앰버 `#C8902E`(전등 불빛 느낌)를 쓰고 싶으면 고동 배경 위에서만 써 (5.16:1, AA). 크림 위에서는 2.33:1이라 글자나 아이콘 색으로 쓰면 안 되고 장식선 정도만 가능해.

## 디자인 생성 프롬프트 (영문, 그대로 붙여넣기)

```
Design a mobile-first landing (index) page for a Korean cafe with a 1970s–80s Korean "dabang" (old-school tearoom) retro concept.

Mood: warm, nostalgic, slightly theatrical. Think dark walnut wood paneling, burgundy velvet booth sofas, frosted glass partitions, warm tungsten lamps, a vinyl record player, a matchbox with the cafe logo, ssanghwa-tea served with a raw egg yolk, and a handwritten chalkboard menu. Modern and clean layout underneath; the retro feel comes from color, type, texture and small details, not clutter.

Color palette (use only these three colors, plus tints of them):
- Background: cream #F4E9D4
- Primary / text / header & footer: walnut brown #3B2418
- Accent / CTA / active states: red-bean burgundy #8C2F2B
Keep body text walnut brown on cream. Never put burgundy text on brown.

Typography: a Korean serif (Myeongjo style, e.g. Nanum Myeongjo or Gowun Batang) for headings, slightly condensed and bold like an old shop sign; a clean Korean sans (Pretendard) for body text at 16px+. Use vertical Korean text or Hanja-style seals as small decorative accents only.

Texture & details: subtle paper grain on the background, thin double-line borders like an old menu, rounded-corner frames like a matchbox label, a stamped circular logo, small starburst price tags, dotted leader lines between menu items and prices.

Page sections (top to bottom):
1. Header: cafe logo (stamp style), nav links (Menu, About, Location), and a "Reserve" button.
2. Hero: big serif headline in Korean, short tagline, a warm photo of the interior with lamp light, primary CTA button "메뉴 보기".
3. Signature menu: 3–4 cards (ssanghwa-tea, dalgona coffee, cream soda, toast) with photo, name, short description, price.
4. Our story: short paragraph with an old-photo style image (sepia frame, slight tilt).
5. Music corner: a "today's LP" card with a record graphic.
6. Visit us: address, opening hours, small map, phone link.
7. Footer: dark walnut background, cream text, social links.

Accessibility: WCAG AA contrast for all text, visible focus rings (burgundy or cream outline 2px with offset), state never shown by color alone, buttons at least 44px tall, meaningful alt text for photos.

Output: a single responsive page, 390px mobile frame first, plus a 1440px desktop version.
```

## 쓸 때 팁

- 메뉴 카테고리 탭이나 '영업 중' 같은 상태 표시는 버건디 색만으로 구분하지 말고 밑줄, 아이콘, 텍스트를 같이 써.
- 포커스 링은 크림 배경에선 버건디, 고동 배경에선 크림으로 바꿔야 잘 보여.
