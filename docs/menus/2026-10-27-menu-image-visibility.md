# 전체 메뉴 이미지 가독성 개선

## 한눈에
- 끝나면: 36개 메뉴 사진의 원래 경로에서 커피 v3와 같은 방식으로 밝힌 새 사진이 보인다.
- 결정 필요: 없음
- 규모: 3단계

## 1. 전체 메뉴 목록 (R1)
공개 메뉴 목록의 모든 사진을 카드 크기는 유지하면서 더 잘 보이게 한다.

S1 정상
- Given `/menus`에 커피와 차 등 메뉴 사진이 표시된다.
- When 목록을 연다.
- Then 카드의 4:3 크기는 그대로이고 사진은 기존보다 밝게 보인다.

S2 품절
- Given 품절 메뉴 사진이 있다.
- When 목록을 연다.
- Then 품절 사진의 회색 처리는 유지된다.

## 2. 커피 승인 이미지 (R2)
승인된 원래 크기의 밝은 커피 사진을 기존 메뉴 이미지 경로에 적용한다.

S3 정상
- Given 커피의 이미지 주소가 `/images/menus/coffee.jpg`다.
- When 목록이나 상세를 연다.
- Then `coffee.jpg`에서 승인된 `coffee-v3.jpg`와 같은 사진이 표시된다.

## 3. 상세 화면 (R3)
공개 메뉴 상세 사진에도 각 메뉴의 새 사진을 표시한다.

S4 정상
- Given 커피 이외의 메뉴 상세가 열린다.
- When 사진을 본다.
- Then 기존 4:3 크기와 구도로 더 밝게 보인다.

## 범위 밖
- 관리자 메뉴 데이터의 이미지 주소 변경
- 메뉴 카드와 상세의 크기·레이아웃 변경

## 작업 순서
1. 원본을 참조해 36개 밝은 메뉴 사진 생성 — S1, S3, S4
   - 파일: `frontend/public/images/menus/*.jpg`
   - 확인: 모든 원래 메뉴 이미지 경로에 새 사진이 있는지 확인
2. 기존 이미지 경로에 새 사진 적용 — S1~S4
   - 파일: `frontend/public/images/menus/*.jpg`
   - 확인: 브라우저의 전체 메뉴·품절 메뉴·상세
3. 정적 검증 — S1~S4
   - 파일: 없음
   - 확인: `npm run lint`, `npm run typecheck`

## 가정
- 사용자가 말한 메뉴 크기는 사진 속 피사체의 크기와 메뉴 카드 크기를 모두 뜻하므로 둘 다 유지한다.
- Git 이력에 원본 사진이 남으므로 기존 URL에서 사진 파일을 교체한다. (고침 10-27: CSS 밝기 효과는 승인된 커피 v3와 같지 않다는 사용자 지적)
