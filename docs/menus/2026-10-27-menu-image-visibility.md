# 전체 메뉴 이미지 가독성 개선

## 한눈에
- 끝나면: 공개 메뉴 목록과 상세에서 모든 메뉴 사진이 기존 크기와 구도를 유지하며 더 밝게 보인다.
- 결정 필요: 없음
- 규모: 3단계, 약 30분

## 1. 전체 메뉴 목록 (R1)
공개 메뉴 목록의 모든 사진을 카드 크기는 유지하면서 더 잘 보이게 한다.

S1 정상
- Given `/menus`에 커피와 차 등 메뉴 사진이 표시된다.
- When 목록을 연다.
- Then 카드의 4:3 크기는 그대로이고 사진은 기존보다 밝게 보인다.

S2 품절
- Given 품절 메뉴 사진이 있다.
- When 목록을 연다.
- Then 품절 사진의 회색 처리는 유지된다.

## 2. 커피 승인 이미지 (R2)
승인된 원래 크기의 밝은 커피 사진을 공개 메뉴에 표시한다.

S3 정상
- Given 커피의 이미지 주소가 `/images/menus/coffee.jpg`다.
- When 목록이나 상세를 연다.
- Then `coffee-v3.jpg`가 표시된다.

## 3. 상세 화면 (R3)
공개 메뉴 상세 사진에도 목록과 같은 밝기 개선을 적용한다.

S4 정상
- Given 커피 이외의 메뉴 상세가 열린다.
- When 사진을 본다.
- Then 기존 4:3 크기와 구도로 더 밝게 보인다.

## 범위 밖
- 관리자 메뉴 데이터의 이미지 주소 변경
- 메뉴 사진의 피사체나 배경 재생성

## 작업 순서
1. 승인된 커피 사진 저장 — S3
   - 파일: `frontend/public/images/menus/coffee-v3.jpg`
   - 확인: 브라우저의 커피 목록·상세
2. 공개 메뉴 이미지 표시 조정 — S1~S4
   - 파일: 공개 메뉴 카드·상세 컴포넌트와 CSS, 이미지 경로 함수
   - 확인: 브라우저의 전체 메뉴·품절 메뉴·상세
3. 정적 검증 — S1~S4
   - 파일: 없음
   - 확인: `npm run lint`, `npm run typecheck`

## 브랜치·커밋
- 브랜치: `feature/clear-coffee-image`
- 커밋: `feat: 전체 메뉴 이미지 가독성 개선`

## 가정
- 사용자가 말한 메뉴 크기는 사진 속 피사체의 크기와 메뉴 카드 크기를 모두 뜻하므로 둘 다 유지한다.
- 커피 이외의 사진은 원본을 유지하고 화면 밝기만 조정한다.

## 참고
- 2026-10-27: 공개 메뉴 카드와 상세는 `object-fit: cover`를 사용한다.
