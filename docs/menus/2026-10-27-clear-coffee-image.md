# 커피 메뉴 이미지 가독성 시험

## 한눈에
- 끝나면: 기존 커피 사진을 유지한 채 밝고 크게 보이는 시험 이미지를 한 장 확인할 수 있다.
- 결정 필요: 없음
- 규모: 2단계, 약 20분

## 1. 한 메뉴 시험 이미지 (R1)
커피 메뉴 사진 한 장을 화면의 4:3 이미지 영역에서 음료가 잘 보이도록 만든다.

S1 정상
- Given 기존 커피 사진에는 어두운 배경이 넓게 보인다.
- When 새 커피 사진을 4:3 영역에 표시한다.
- Then 컵과 받침이 중앙에서 크게 보이고 커피 표면과 컵 무늬를 식별할 수 있다.

## 2. 원본 보존 (R2)
시험 이미지를 별도 파일에 저장하고 기존 커피 사진은 유지한다.

S2 정상
- Given `coffee.jpg`가 있다.
- When 새 이미지를 저장한다.
- Then `coffee-v2.jpg`와 기존 `coffee.jpg`가 함께 있다.

## 범위 밖
- 다른 메뉴 사진의 교체
- 메뉴별 이미지 주소 데이터 수정

## 작업 순서
1. 커피 사진 생성 및 저장 — S1, S2
   - 파일: `frontend/public/images/menus/coffee-v2.jpg`
   - 확인: `sips -g pixelWidth -g pixelHeight frontend/public/images/menus/coffee-v2.jpg`
2. 카드 크기로 시각 확인 — S1
   - 파일: 없음
   - 확인: 4:3 축소 화면 확인

## 브랜치·커밋
- 브랜치: `feature/clear-coffee-image`
- 커밋: `feat: 커피 메뉴 시험 이미지 추가`

## 가정
- 첫 시험 대상으로 기존 커피 메뉴를 사용한다.
- 원본과 나란히 비교할 수 있도록 새 파일은 아직 메뉴 데이터에 연결하지 않는다.

## 참고
- 2026-10-27 확인: 공개 메뉴 카드와 상세 이미지는 모두 4:3 영역에 `object-fit: cover`로 표시한다.
