# 장바구니 페이지 기획

## 목표
- 이번 작업 범위: **장바구니 조회/수정 기능만**
- 구매(결제) 단계는 포함 안 함 — 나중에 다른 팀원이 주문/결제 페이지 머지할 때 이어붙일 것

## 화면 구성
- 장바구니 아이템 목록 (이미지, 이름, 가격, 수량)
- 각 아이템 앞에 **체크박스** — 선택한 아이템만 합계에 반영
- 전체 선택/해제 체크박스
- 수량 증감 (+/-)
- 개별 삭제 버튼
- 하단에 "선택 상품 합계" 금액 표시
- "주문하기" 버튼 — 선택된 상품 없으면 비활성화, 클릭 시 "주문 기능은 준비 중입니다" 안내만 (실제 주문/결제 로직은 이번 범위 아님, 자리만 만들어둠)

## 데이터
- **백엔드 API가 나중에 붙을 자리** — 지금은 mock 저장소(파일 기반) 안 만들고 클라이언트 state로만 처리
- 초기 아이템은 데모용 배열 하나를 컴포넌트 안에 박아둠 (나중에 `GET /cart` 같은 API 응답으로 교체될 자리)
- 체크박스/수량/삭제는 전부 로컬 state 조작, 서버 액션 불필요

## 라우트
