# 삼다방

레트로 다방을 콘셉트로 한 카페 서비스입니다. 기존 백엔드와 데이터베이스를 사용하며, 이번 프로젝트에서는 프론트엔드 화면과 기능을 구현합니다.

## 주요 기능

### 메인 페이지

- 카페 콘셉트와 추천 메뉴를 소개합니다.
- 뮤직박스의 현재 선곡과 도착한 사연을 미리 보여줍니다.
- 메뉴와 뮤직박스, 매장 안내로 이동할 수 있습니다.

### 메뉴 페이지 및 상세 페이지

- 카테고리와 검색 조건으로 메뉴를 찾을 수 있습니다.
- 메뉴의 이미지, 이름, 가격, 설명과 판매 상태를 확인할 수 있습니다.
- 메뉴 온도와 수량을 선택하고 장바구니에 담을 수 있습니다.

### 장바구니 페이지

- 담은 메뉴와 온도, 수량, 가격 및 합계를 확인할 수 있습니다.
- 메뉴 수량을 변경하거나 항목을 삭제하고 주문할 수 있습니다.

### 뮤직박스 페이지

- 현재 선곡과 재생 정보, 신청곡과 사연을 확인할 수 있습니다.
- 사연과 신청곡을 보낼 수 있으며, 마이페이지의 신청 내역 관리 기능으로 이동할 수 있습니다.

### 주문 목록 - 주문 상세 페이지

- 진행 중인 주문과 지난 주문을 확인할 수 있습니다.
- 주문 번호, 일시, 상태, 메뉴와 금액을 확인할 수 있습니다.
- 주문을 취소하거나 목록으로 돌아갈 수 있습니다.

### 마이페이지

- 회원 정보를 확인하고 장바구니, 주문 목록으로 이동할 수 있습니다.
- 로그아웃할 수 있습니다.

#### 마이페이지 - 나의 사연 및 신청곡 관리

- 내가 보낸 사연과 신청곡을 카드 형태로 확인하고 삭제할 수 있습니다.
- 마이페이지와 뮤직박스 페이지에서 해당 기능으로 이동할 수 있습니다.

### 관리자 페이지 - 신청곡 관리

- 접수된 신청곡과 사연, 현재 선곡을 확인할 수 있습니다.
- 음원 주소를 등록하고 재생 가능 여부를 확인할 수 있습니다.
- 신청곡의 선곡과 처리 상태를 관리할 수 있습니다.

## 주요 이용 흐름

1. 메인 페이지나 메뉴 페이지에서 메뉴를 살펴봅니다.
2. 메뉴 상세 페이지에서 온도와 수량을 선택해 장바구니에 담습니다.
3. 장바구니에서 메뉴와 수량을 확인하고 주문합니다.
4. 주문 목록과 상세 페이지에서 주문 상태와 내역을 확인합니다.
5. 뮤직박스에서 사연과 신청곡을 보내고, 마이페이지에서 신청 내역을 확인하거나 삭제합니다.
6. 관리자는 관리자 페이지에서 신청곡을 확인하고 선곡 및 처리 상태를 관리합니다.
