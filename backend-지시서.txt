백엔드 txt내용대로 프로젝트를 만들기 위한 청사진 파일을 만들어줘
나 스프링부트로 백엔드 만들어줘
- jdk 버전은 21인데, 그것에서 사용할 수 있는 스프링 부트 최신 버전으로 해주고
- backend 이름으로 프로젝트 명을 만들어주고
- 패키지 명은 [com.new](http://com.new/)-cafe.backend로 해주고
- RestAPI를 개발하기 위한 라이브러리를 추가해주는데, 최소한의 라이브러리만 추가해주고 JPA나 Lombok등은 추가하지마 최소한의 web 라이브러리만 추가해줘
- api를 구현하기 위한 아키텍처는 3계층 아키텍처로 해줘
- 빌드도구는 gradle을 이용해서 해야 해
- 기본적으로 구현할 내용은 다음과 같아
- 관리자가 메뉴를 관리하는 기능
- 사용자가 메뉴를 조회하는 기능
- 회원이 메뉴를 장바구니에 관리하는 기능
- 회원이 메뉴 주문을 관리하는 기능
- 사용자용 랜딩페이지
- 회원용 대시보드 기능
- 관리자용 대시보드 기
